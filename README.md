# AI Assistant Platform

A modular AI chatbot platform built with specialized agents, deterministic tools, conversational memory, and orchestration principles.

The primary goal of this project is not only to build a chatbot, but also to provide practical experience with concepts commonly used in modern AI systems, including:

* Agent orchestration
* Tool calling
* Conversational memory
* Prompt engineering
* Guardrails
* Separation of concerns
* Modular software architecture

---

# Project Overview

The application receives a user request, determines whether the request contains a mathematical operation, executes the calculation using deterministic tools, and finally generates a human-friendly response through a specialized communication agent.

The system demonstrates how multiple specialized agents can collaborate while maintaining strict responsibility boundaries.

---

# Features

## Mathematical Operations

Supported operations:

* Addition
* Subtraction
* Multiplication
* Division

All mathematical calculations are executed through dedicated Python functions rather than LLM reasoning.

This guarantees deterministic and reliable results.

---

## Specialized AI Agents

### Mathematical Agent

Responsible for:

* Detecting mathematical requests
* Extracting operands
* Identifying operations
* Selecting the appropriate tool
* Executing calculations

Restrictions:

* Cannot answer general knowledge questions
* Cannot generate conversational responses
* Cannot perform reasoning outside mathematical operations

---

### Writer Agent

Responsible for:

* Transforming raw results into user-friendly responses
* Improving readability
* Preserving the user's language
* Generating natural responses

Restrictions:

* Never performs calculations
* Never invents numbers
* Only communicates results generated by other components

---

## Agent Orchestration

The system contains a dedicated orchestration layer responsible for:

1. Receiving user input
2. Classifying intent
3. Selecting the appropriate agent
4. Coordinating information flow
5. Returning the final response

Agents never communicate directly with the user or with each other.

All communication passes through the orchestrator.

---

## Conversational Memory

The chatbot maintains session state and conversation history.

This allows follow-up interactions such as:

User:

```text
What is 5 + 4?
```

Assistant:

```text
9
```

User:

```text
Now subtract 2.
```

Assistant:

```text
7
```

---

## Guardrails

Each agent operates within clearly defined boundaries.

Examples:

* The Mathematical Agent only performs calculations.
* The Writer Agent only generates responses.
* The Orchestrator only coordinates execution flow.

This prevents responsibility leakage and improves maintainability.

# Installation

Clone the repository:

```bash
git clone <repository-url>
cd ai_assistant_platform
```

Create a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure environment variables:

```env
OPENAI_API_KEY=your_api_key
MODEL_NAME=gpt-4o-mini
LLM_PROVIDER=openai
```

---

# Running the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will be available locally through the browser.
